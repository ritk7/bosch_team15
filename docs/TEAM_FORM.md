**Team name:** No-15 "Lil bosch"

**Project:** Chaos Sentinel: an AI that predicts what a failure will do, injects it safely behind a plain-code kill switch,
proves every unit of work that silently disappeared, recommends the fix, and re-runs to prove the fix worked.
**Repository:** https://github.com/ritk7/bosch_team15

## AI models used
| Model | Where | Role |
|---|---|---|
| Claude Haiku 4.5 (Anthropic), via an OpenAI-compatible router | inside the product | the 3 agents: planner (ranks, picks, predicts), risk (explains findings), fix (recommends fixes) |
| Llama 3.2 3B (Meta), via Ollama | inside the product, optional | free local tier |
| Deterministic rules | inside the product | fallback for every agent; the product works with no AI key |
| Claude Code (Anthropic, Opus) | development | pair programming: code, tests, Docker verification |
